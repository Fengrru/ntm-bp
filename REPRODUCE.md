# Reproducibility Package

**Paper:** *Selective Belief Propagation for Efficient Truth Maintenance in
LLM Agents* — Yuhan Feng, 2026 (S.-T. Yau High School Science Award, CS).

This package is self-contained: it ships the numeric engine, the dataset
generators, the datasets, the dual-annotator labels, the **complete frozen
prompts**, and the **prompt-hash cache**, so the paper's reported numbers can
be reproduced either from generators (numeric results) or from the cache
(LLM results) **without an API key and without network access**.

## 0. Requirements

- Python ≥ 3.9 (no GPU).
- The engine and every core experiment run on the **standard library only**.
- Three optional numeric scripts use NumPy:
  `requirements-repro.txt` (`pip install -r requirements-repro.txt`).
- `pytest` for the test suite (`pip install -e .[test]`).

```bash
pip install -e .
```

## 1. Offline verification (recommended first step)

Replays every frozen LLM prompt from `data/llm_gate_cache.json`, recomputes
the paper's Tables 2–4 and 10–12 at the instance level, and asserts each
value against the paper. A cache miss aborts (no network fallback), so a
PASS is proof that the committed cache + datasets + engine reproduce the
paper.

```bash
python scripts/reproduce_paper_tables.py
```

Expected tail:

```
PASS: all 30 numbers reproduce from the committed cache.
```

## 2. Reproduce the numeric results from generators

Datasets are regenerated byte-for-byte (seeds 42 / split seed 20260731):

```bash
python scripts/generate_pc500.py
python scripts/generate_syndep.py
python scripts/generate_co_relation_test.py
python scripts/generate_scalability_graphs.py
python scripts/make_case_split.py
python scripts/generate_expansion.py     # unlabeled cases + blind sheet
```

Main comparison (Figure 1) and the numeric ablations:

```bash
python scripts/run_main_eval.py              # Figure 1
python scripts/run_co_relation_eval.py       # Table 13 (CO relation types)
python scripts/experiment_gamma_analysis.py  # Table 6
python scripts/experiment_cpt_sensitivity.py # Table 8
python scripts/experiment_walksum_verification.py
python scripts/experiment_ablation_components.py
python scripts/experiment_significance.py         # paired cluster bootstrap + subsets + call budget
python scripts/experiment_gate_ablation.py        # Table 9 (structured-gate component ablation)
python scripts/experiment_scalability_latency.py  # Table 7 methodology (hardware-specific)
```

All experiment scripts are deterministic and write their JSON result to
`data/`. Numbers are verified in `docs/reproducibility.md`.

## 3. Test suite

```bash
python -m pytest -q        # 52 tests
```

## 4. Package verification helper

`python verify_submission.py` runs the non-LLM experiments and prints the
paper's target numbers for a quick visual check. `reproduce_paper_tables.py`
is the stricter, machine-checked verifier.

> **Table 4 note.** The paper stratifies the 54 Expansion-500 cases by a
> 50-keyword lexical-marking rule (22 marked / 32 unmarked). The correct
> aggregation is the **instance-level macro mean** used everywhere else in
> the paper; `reproduce_paper_tables.py` applies it and yields
> NTM-BP = **0.771 / 0.628** (marked / unmarked), consistent with the
> overall 0.686. A separate ad-hoc analysis script had averaged only the
> last jitter instance per case, which is not the paper's metric.

## 6. Integrity

- `MANIFEST.sha256` lists a SHA-256 for every file in the package.
- `data/llm_gate_cache.json` (954 unique prompts, 878 KB) is the frozen
  audit trail; prompts are hashed by SHA-256 and never edited after freeze.
- One-shot discipline: `experiment_sealed_test.py` and
  `experiment_expansion_eval.py` refuse to overwrite existing result files.
