# Reproducibility Guide

This repository reproduces the numbers reported in the NTM paper
("Selective Belief Propagation for Efficient Truth Maintenance in
LLM Agents", Yuhan Feng, 2026) from its committed generators alone --
every dataset file under `data/` is regenerated by the scripts, and the
evaluation pipeline is deterministic (seeds 42 / 20260731).

## 1. Regenerate all datasets

```bash
python scripts/generate_pc500.py             # -> data/pc500.json (500 instances)
python scripts/generate_syndep.py            # -> data/syndep.json (200 instances)
python scripts/generate_scalability_graphs.py# -> data/scalability/scalability_graphs.json
python scripts/generate_co_relation_test.py  # -> data/co_relation_test.json (8 scenarios)
python scripts/make_case_split.py            # -> data/case_split.json (frozen dev/test split)
```

All generators use fixed seeds (`random.Random(42)`, split seed
`20260731`) and the ±0.05 jitter is clamped to `[0.05, 0.99]`, so the
outputs are byte-identical on every platform and Python version ≥ 3.9.

## 2. Reproduce Figure 1 (main three-way comparison)

```bash
python scripts/run_main_eval.py
```

Configuration: `tau=0.7, gamma=0.7, cutoff=0.01`, all three methods on
both datasets. Results are saved to
`data/experiment_main_results.json`.

If any number differs, run the audit below before touching the engine.

## 3. Reproduce the CO relation-type ablation (Sec 6.7 negative result)

```bash
python scripts/run_co_relation_eval.py
```

Expected F1 on PC-500: `supports` ≈ 0.857, `contradicts` ≈ 0.873,
`neutral` ≈ **0.709** (degradation), `mixed` ≈ 0.813 (verified
byte-identical against the research repository's
`experiment_co_relation_results.json`). The all-neutral degradation is
why CO ships under `ntm_bp.experimental`.

## 4. LLM gate pipeline (mock plumbing test)

```bash
python scripts/run_gate_eval.py --mock --dataset pc500
python scripts/audit_cache.py
```

The mock run exercises the full pipeline (prompt building → LLM call →
parsing → reeval marking → call log) without spending tokens. **Mock
results are NOT experimental evidence** -- the committed
`data/gate_call_log.json` is exactly such a mock run (`"mock": true`).
For real numbers set
`DEEPSEEK_API_KEY` and run without `--mock`; audit the resulting
`data/gate_call_log.json` the same way. The sealed-test and
Expansion-500 gate numbers in the paper were produced in the research
repository from its frozen prompt-hash cache.

## Known porting difference

The original research code wrapped `networkx`; this repository uses
plain dict adjacency lists (identical traversal semantics, deterministic
node ordering). The metrics are numpy-free. All numbers above were
re-verified against the research repository's `experiment_main_results.json`
before shipping.
