# Reproducibility Guide

This repository reproduces the numbers reported in the NTM paper
("Selective Belief Propagation for Efficient Truth Maintenance in
LLM Agents", Yuhan Feng, 2026) from its committed generators alone --
every dataset file under `data/` is regenerated by the scripts, and the
evaluation pipeline is deterministic (seeds 42 / 20260731).

See the top-level `REPRODUCE.md` for the end-to-end, ordered procedure.

## 0. Offline verification of the LLM-derived tables (zero API)

```bash
python scripts/reproduce_paper_tables.py
```

Replays every frozen prompt from `data/llm_gate_cache.json`, recomputes
Tables 2–4 and 10–12 at the instance level, and asserts each value against
the paper (30 checks). A cache miss aborts instead of calling the API, so
a PASS proves the committed cache + datasets + engine reproduce the paper.

> Table 4 (lexical stratification) is recomputed here at the instance level:
> NTM-BP marked/unmarked = 0.771 / 0.628 (overall 0.686). An older ad-hoc
> script averaged only the last jitter instance per case, giving 0.736 /
> 0.619; that estimator is not the paper's macro-averaged metric.

## 1. Regenerate all datasets

```bash
python scripts/generate_pc500.py             # -> data/pc500.json (500 instances)
python scripts/generate_syndep.py            # -> data/syndep.json (200 instances)
python scripts/generate_scalability_graphs.py# -> data/scalability/scalability_graphs.json
python scripts/generate_co_relation_test.py  # -> data/co_relation_test.json (8 scenarios)
python scripts/make_case_split.py            # -> data/case_split.json (frozen dev/test split)
```

All generators use fixed seeds (`random.Random(42)`, split seed
`20260731`) and the ±0.05 jitter is clamped to `[0.05, 0.99]`, so the
outputs are byte-identical on every platform and Python version ≥ 3.9.

## 2. Reproduce Figure 1 (main three-way comparison)

```bash
python scripts/run_main_eval.py
```

Configuration: `tau=0.7, gamma=0.7, cutoff=0.01`, all three methods on
both datasets. Results are saved to
`data/experiment_main_results.json`.

## 3. Reproduce the CO relation-type ablation (Sec 6.7 negative result)

```bash
python scripts/run_co_relation_eval.py
```

Expected F1 on PC-500: `supports` ≈ 0.857, `contradicts` ≈ 0.873,
`neutral` ≈ **0.709** (degradation), `mixed` ≈ 0.813 (byte-identical to
`data/experiment_co_relation_results.json`). The all-neutral degradation is
why CO ships under `ntm_bp.experimental`.

## 3b. Significance, subsets, and call budget

```bash
python scripts/experiment_significance.py
```

Offline from the frozen cache (zero API): paired cluster-bootstrap tests
(case-level clusters, 2,000 resamples, seed 42, two-sided
$p=2\min(\Pr[\Delta^*\le0],\Pr[\Delta^*\ge0])$), the unmarked-subset tests,
empty/non-empty subset means, the case-level win/loss breakdown, and the
audited call budget.  Expected: structured$-$BFS $p<0.001$;
structured$-$NTM-BP $p=0.18$; structured$-$gate-v1 $p=0.14$; unmarked
structured$-$gate-v1 $p=0.037$; unmarked structured$-$NTM-BP $p=0.57$;
structured 2.87 vs. gate-v1 2.28 calls/update.  Output:
`data/experiment_significance_results.json`.

## 3c. Scalability latency (Table 7 methodology)

```bash
python scripts/experiment_scalability_latency.py
```

Benchmarks the shipped dependency-free port on the deterministic
scalability graphs (seed 42, 20 graphs/size).  Absolute millisecond values
are hardware/interpreter-specific; the paper's Table 7 numbers were measured
on the original research build (i7-12700H / Python 3.11).  Output:
`data/experiment_scalability_latency_results.json`.

## 3d. Structured-gate component ablation (Table 9)

```bash
python scripts/experiment_gate_ablation.py
```

Replays the frozen gate and two ablated variants (`-Q3` = B always skips;
`-Q2` = binary relevance replaced by the v1 scalar impact) plus the scalar
gate-v1 baseline, on the SynDep dev (12 cases) and sealed-test (18 cases)
splits.  Cache-only; a cache miss aborts.  Expected: dev
0.735/0.823/0.823/0.520 and test 0.807/0.807/0.800/0.692 for
Full/NoQ3/ScalarQ2/gate-v1.  The `-Q1 early-exit removed` variant cannot be
replayed offline (its type-C relevance prompts were never issued by the
frozen gate) and is therefore not reported.  Output:
`data/experiment_gate_ablation_results.json`.

## 4. LLM gate pipeline (mock plumbing test)

```bash
python scripts/run_gate_eval.py --mock --dataset pc500
python scripts/audit_cache.py
```

The mock run exercises the full pipeline (prompt building → LLM call →
parsing → reeval marking → call log) without spending tokens. **Mock
results are NOT experimental evidence.** For real numbers set
`DEEPSEEK_API_KEY` and run without `--mock`; audit the resulting call log
the same way. The sealed-test and Expansion-500 gate numbers in the paper
are reproduced here from the committed frozen prompt-hash cache with zero
API calls by `scripts/reproduce_paper_tables.py` (see section 0).

## Known porting difference

The original research code wrapped `networkx`; this repository uses
plain dict adjacency lists (identical traversal semantics, deterministic
node ordering). The metrics are numpy-free. All numbers above are
re-verified by the scripts in this package (and by CI) before shipping.
